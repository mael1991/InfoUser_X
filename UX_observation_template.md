# StudyBuddy UX Observation Log Template

Use this template during live or recorded UX observation sessions. Keep all entries factual and separate from interpretation.

Important rules:
- Do not estimate or invent timestamps or durations.
- Use exact times from your recording or stopwatch.
- If any time is missing, write: time unknown
- Separate facts from interpretations in different columns/fields.
- Log short commands exactly as spoken or typed: ob, q, b, pp, i

## 3) Short command log

Command legend:
- ob = observation (factual, no interpretation)
- q = quote (verbatim participant statement)
- b = behavior (what the participant did)
- pp = pain point (problem or friction observed or expressed)
- i = insight (interpretation or takeaway)

Use this format for each event:

Command | Exact time | Relative time from task start | Task progress % | Factual description | Interpretation / meaning | Notes

Examples:

| Command | Exact time | Relative time from task start | Task progress % | Factual description | Interpretation / meaning | Notes |
|---|---:|---:|---:|---|---|---|
| ob | 09:14:22.400 | 00:00:00.000 | 0% | Participant opened StudyBuddy home screen. |  | App loaded with default course list. |
| q | 09:15:11.230 | 00:00:48.830 | 8% | "I want to find a study group for my statistics class." | Need to locate course-specific groups quickly. | Verbatim quote. |
| b | 09:15:44.510 | 00:01:22.110 | 12% | Participant tapped search and typed "STAT". |  | Search field was used before browsing. |
| pp | 09:17:03.880 | 00:02:41.480 | 25% | Participant said they could not tell which group was closest to campus. | Missing location detail creates uncertainty. |  |
| i | 09:17:35.700 | 00:03:13.300 | 31% | Participant hesitated before joining a group because the schedule was not obvious. | Trust barrier may be reduced by clearer time/location metadata. | Interpretation only. |

## 7) Example of separation between facts and interpretations

Facts (keep objective):
- Participant tapped the course filter twice.
- Participant looked confused at the group card.
- Participant said, "I don't know which session is closest."
- Participant exited the screen after 15 seconds without selecting a group.

Interpretations (do not mix with facts):
- The participant may be overwhelmed by too much information.
- The interface likely lacks strong signposting for course match confidence.
- The participant seems to distrust the location details.
